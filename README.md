# The Room Is

A VR escape-room style Unreal project — a potion-brewing room with
interactive props.

Commit history tracks the build: adding 3D models to the map, potion
pouring with colour change, fire under the cauldron.

**Engine:** Unreal Engine · **Logic:** Blueprints · **VR:** VRExpansionPlugin

The VRExpansionPlugin (third-party) and build caches are excluded; install
the plugin separately to open the project.
